# Микаил Дадашов — персональное портфолио

Интерактивное портфолио веб-дизайнера и разработчика: крупная типографика, настоящий портрет, реакция изображения на курсор, анимированное меню и отдельные кейсы CUDGI и Brand Builder.

Сайт: https://mikail-portfolio-interactive.vercel.app/

Открытый репозиторий: https://github.com/rumulzzzz-crypto/mikail-portfolio-interactive

## Разработка

Требуется Node.js 22+ и pnpm.

```sh
pnpm install
pnpm dev
```

Локальный адрес: http://localhost:3100.

```sh
pnpm typecheck
pnpm build
pnpm start
```

## Устройство

- Next.js App Router, React, TypeScript.
- GSAP / ScrollTrigger / ScrambleText и Lenis для движения и навигации.
- Проявление портрета через мягкую Canvas 2D-маску; фотография доступна без эффектов.
- Отложенно загружаемая локальная 3D-галактика с постером при отказе WebGL.
- Лаборатория `/lab`: эффект света и адаптированная реакция кнопки/карточки, с клавиатурой и уменьшенной анимацией.
- Web Audio: оригинальная синтезированная атмосфера и звуки взаимодействий. Включаются пользователем; настройка запоминается. Сторонняя музыка не используется.
- Локальные шрифты Oswald и Manrope, кириллица.
- Мобильная компоновка, клавиатурная навигация, native dialog и prefers-reduced-motion.

Тексты проектов и внешние ссылки находятся в `lib/projects.ts`, главная — в `components/Home.tsx`, контакты и меню — в `components/Shell.tsx`. Медиа — в `public/images`. Секреты и переменные окружения для работы сайта не требуются.

## Публикация

Проект предназначен для Vercel с автоматическим определением Next.js. Корень репозитория является корнем приложения; команда сборки `pnpm build`. Production-ветка: `main`.

В настройках Vercel выбран Framework Preset `Next.js`, подключён GitHub-репозиторий. Изменения в `main` запускают публикацию. Защита развёртываний входом в Vercel отключена для этого публичного портфолио.

Референс художественного направления: https://curtisdesignr.me/. Материалы референса не используются. Фотография предоставлена владельцем портфолио. Скриншоты показывают публичные демонстрации его проектов; статусы демо описаны в кейсах без вымышленных коммерческих результатов. Часть взаимодействий адаптирована из SmoothUI (MIT); Galaxy использует стороннюю модель (CC BY 4.0). Источники указаны на `/credits`, лицензии сохранены в `docs/vendor`, `public/fonts` и документации модели.
