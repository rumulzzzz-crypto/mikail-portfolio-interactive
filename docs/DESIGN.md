# Микаил Дадашов — интерактивное портфолио

Визуальная теза: персональный цифровой портрет, который переходит в витрину двух реальных проектов. Референс поведения — curtisdesignr.me. Реализация и оформление самостоятельные.

Палитра: ink #090a08, paper #f0f1e9, acid #b6ff43, muted #969b8d, line #30332b. Oswald для крупных заголовков, Manrope для чтения, оба со встроенной кириллицей и локальными файлами через Fontsource.

Композиция: компактная верхняя навигация → большой портрет справа и имя в нижней трети → зелёная секция о подходе → два разноуровневых проекта → зелёный контактный экран. На телефоне портрет сохраняет квадратные пропорции, имя располагается ниже лица.

Эффекты: независимый WebGL-шейдер портрета (локальный displacement и RGB split), GSAP entrance и короткий desktop pin, scramble коротких подписей, панель меню и звуковая обратная связь. Основной текст и маршруты доступны без WebGL и при reduced motion.

Исходные материалы: фотография предоставлена владельцем; обложки — скриншоты публичных демо CUDGI и Brand Builder, снятые 24 сентября 2026. Никакие кейсы или музыкальные файлы референса не скопированы. Звуковая подложка — временные синтезированные гармоники Web Audio, музыка для финальной версии выбирается отдельно.
